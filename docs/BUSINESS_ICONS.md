# Business icon mapping

The app uses `@expo/vector-icons/Ionicons`, included with Expo.

- Home: `home-outline`
- Bank/accounts: `card-outline` or `business-outline`
- Messages: `chatbubble-outline`
- Profile: `person-outline`
- Create account: `add-circle-outline`
- Security: `shield-checkmark-outline`
- Privacy: `lock-closed-outline`
- Community: `people-outline`
- Trust: `hand-left-outline`
- Payments: `cash-outline`
- Transfers: `swap-horizontal-outline`
- History: `receipt-outline`
- Fraud warning: `warning-outline`
- Support: `headset-outline`

If a business icon is unavailable, use the written feature name rather than adding an unmaintained icon package.
